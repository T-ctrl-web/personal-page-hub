# 自定义域名配置指南（PersonalPage Hub）

网站已上线：**https://t-ctrl-web.github.io/personal-page-hub/**（GitHub Pages）

如果想拥有好记的独立域名，按本指南操作。

## 1. 注册域名

### 后缀选择
| 后缀 | 参考价/年 | 特点 |
|---|---|---|
| `.dev` | ~$12 | 自动 HTTPS，开发者友好（推荐） |
| `.me` | ~$15-20 | 个人品牌感 |
| `.com` | ~$10-15 | 最通用 |
| `.top` / `.xyz` | ~¥10-30 | 便宜 |

### 命名建议
`<名字拼音>.dev`（最好记）或 `myhome.dev` / `pphub.xyz` 等短域名。

### 注册商
- 国内：阿里云 / 腾讯云（需实名，.top/.xyz 很便宜）
- 国外：Cloudflare Registrar / Namecheap（.dev 便宜）

## 2. 配置 DNS（在注册商面板操作）

添加一条 CNAME 记录：

| 字段 | 值 |
|---|---|
| 类型 | CNAME |
| 主机 | `www`（若用根域则填 `@` 或用 A 记录） |
| 值 | `t-ctrl-web.github.io` |

> 若用根域（如 `zhixia.dev` 不带 www），GitHub Pages 建议用 CNAME 到 `t-ctrl-web.github.io`（GitHub 会自动处理）；也可用 A 记录指向 GitHub Pages 的 IP（`185.199.108.153` 等 4 个）。

## 3. 在 GitHub 设置自定义域名

**方式 A（网页）**：仓库 Settings → Pages → Custom domain 填入你的域名 → Save（自动创建 CNAME 文件 + 启用 HTTPS）

**方式 B（API，我可代劳）**：
```powershell
gh api -X PATCH repos/T-ctrl-web/personal-page-hub/pages -f cname=你的域名
```

配置完成后，等待 DNS 生效（几分钟到几小时）+ HTTPS 证书签发（GitHub 自动，通常几分钟），即可访问 `https://你的域名`。

## 4. 验证

- 访问 `https://你的域名` 应显示模板工坊（自动跳转或直接加载）
- 原地址 `https://t-ctrl-web.github.io/personal-page-hub/` 仍可用

## 说明

- 域名需年费续费；DNS 与 HTTPS 由 GitHub Pages 免费处理
- 国内访问 GitHub Pages 有时不稳定，如需国内快速访问可考虑 Gitee Pages（需实名+审核）或加 CDN（如 Cloudflare 免费版）
